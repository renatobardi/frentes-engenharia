# frentes-engenharia

PoC de uma app web que recebe **frentes** — problemas ou oportunidades de tecnologia, processo, pessoas ou incidentes, reativos ou proativos — por várias fontes, classifica cada uma com o **Jev** (TypeSafe, via OpenRouter), enriquece com uma LLM comum (via OpenRouter) e mostra um **mapa de calor** que aponta onde investir.

Objetivo imediato: demonstrar ao diretor, com uma seed grande de dados fictícios.

O planejamento corre como um mapa de wayfinding nas issues do repo (label `wayfinder:map`). Convenções do tracker: [`docs/agents/issue-tracker.md`](docs/agents/issue-tracker.md).
